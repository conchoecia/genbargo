# Embargoed Genome Assemblies Dashboard

_This file is a placeholder. It is regenerated automatically each week by the
[`weekly-embargo-dashboard`](../.github/workflows/weekly.yml) GitHub Action,
which scrapes fresh assembly metadata from NCBI, recomputes embargo status,
links publications, and overwrites this page._

Run it locally with:

```bash
genbargo all --config genbargo.config.yaml
```
